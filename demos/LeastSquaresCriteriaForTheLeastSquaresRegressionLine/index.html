Directions

The least squares regression line is commonly used as the best fitting line to a fixed collection of points. This simulation provides a visualization of the squares used in determining this line. For each of three datasets, the residuals from the points to a line are shown as dashed vertical segments. The squares of the residuals are shown with a red border. You can adjust the slope and intercept of the line in an effort to find the line for which the sum of the areas of these squared residuals is least. Click the button to obtain the least squares regression line.

×

Details

For a set of \(n\) data points \((x_i,\,y_i)\) and a line \(y = m x + b\), the residual at each point is the vertical distance between the observed value and the value predicted by the line:

\[ r_i = y_i - (m x_i + b) \]

The least squares criterion selects the slope \(m\) and intercept \(b\) that minimize the sum of the squared residuals:

\[ S = \sum_{i=1}^{n} \left[\, y_i - (m x_i + b) \,\right]^2 \]

Setting \(\partial S / \partial m = 0\) and \(\partial S / \partial b = 0\) yields the least squares regression line, with:

\[ m = \frac{n \sum x_i y_i - \sum x_i \sum y_i}{n \sum x_i^2 - \left(\sum x_i\right)^2}, \qquad b = \bar{y} - m\,\bar{x} \]

where \(\bar{x}\) and \(\bar{y}\) are the means of the \(x_i\) and \(y_i\) values. In the plot, each shaded square has a side length equal to the magnitude of a residual \(|r_i|\), so its area equals the squared residual \(r_i^2\); the sum of the areas of these squares is the quantity minimized by the least squares regression line.

Symbols

  • \(n\) = number of data points
  • \(x_i\) = \(x\) value of data point \(i\)
  • \(y_i\) = observed \(y\) value of data point \(i\)
  • \(m\) = slope of the line
  • \(b\) = intercept of the line
  • \(r_i\) = residual of data point \(i\)
  • \(S\) = sum of the squared residuals
  • \(\bar{x}\) = mean of the \(x_i\) values
  • \(\bar{y}\) = mean of the \(y_i\) values
