Directions

Select the type of input (step, ramp or sinusoidal) with the "choose input" buttons, and use the sliders to change the time constant \(\tau\) and the input magnitude \(a\). For a sinusoidal input, the angular frequency \(\omega\) can also be varied.

A transfer function is the ratio of the output to the input of a system. The system response is determined from the transfer function and the system input. A Laplace transform converts the input from the time domain to the spatial domain by using Laplace transform relations. The transformed spatial input is multiplied by the transfer function to get the output in the spatial domain. It is then converted back to the time domain using an inverse Laplace transform.

This Demonstration shows the responses to a first-order transfer function. You can vary the magnitude of the input and the time constant \(\tau\). The time constant is related to how long a system takes to reach the new steady state. The input can be a step function, a ramp, or a sinusoidal input.

Details

Step Input and Response

For a step input of magnitude \(a\),

\(s =\) space domain
\(t =\) time domain
\(x(t) = a\)
\(x(s) = \dfrac{a}{s}\)
\(y(s) = \dfrac{K\,a}{s(\tau s + 1)}\)
\(y(t) = K\,a\left(1 - e^{-t/\tau}\right)\)
\(\tau = 0.632\,\Delta SS\)  time constant
\(\Delta SS =\) change in steady states

Ramp Input and Response

For a ramp input of magnitude \(a\),

\(x(t) = a\,t\)
\(x(s) = \dfrac{a}{s^2}\)
\(y(s) = \dfrac{K\,a}{(\tau s + 1)\,s^2}\)
\(y(t) = K\,a\,\tau\left(e^{-t/\tau} - 1\right) + K\,a\,t\)

Sinusoidal Input and Response

\(\omega = 2\pi f\)  angular frequency, rate of change of the function
\(x(t) = a\sin(\omega t)\)
\(x(s) = \dfrac{a\,\omega}{s^2 + \omega^2}\)
\(y(s) = \dfrac{K\,a\,\omega}{(\tau s + 1)(s^2 + \omega^2)}\)
\(y(t) = \dfrac{K\,a\,\omega\,\tau}{\omega^2\tau^2 + 1}\,e^{-t/\tau} + \dfrac{K\,a}{\sqrt{\omega^2\tau^2 + 1}}\sin(\omega t + \phi)\)
\(\phi = -\tan^{-1}(\omega \tau)\)  phase shift, negative value represents a delay
time shift \(= -\dfrac{360}{\phi}\,p\)
amplitude ratio \(= \dfrac{B}{A}\)

Symbols

\(a\) = input magnitude
\(A\) = amplitude of the input
\(B\) = amplitude of the output (response)
\(f\) = frequency (1/min)
\(K\) = process gain
\(p\) = period of the sinusoidal input (min)
\(s\) = Laplace transform variable
\(t\) = time (min)
\(x\) = input
\(y\) = output (response)
\(\Delta SS\) = change in steady state
\(\tau\) = time constant (min)
\(\phi\) = phase shift (rad)
\(\omega\) = angular frequency (rad/min)
