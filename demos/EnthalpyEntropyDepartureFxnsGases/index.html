This Demonstration plots the enthalpies and entropies for a real gas and an ideal gas as a function of temperature, relative to a reference state at a selected pressure and temperature, using the Peng–Robinson equation of state and ideal-gas heat capacities. Select argon, benzene, or carbon dioxide with buttons. For each gas, the temperature scale is adjusted so the plots are only shown above the critical temperature. Select enthalpy or entropy departure function, which is the difference between the thermodynamic property (enthalpy, entropy) for a real gas and an ideal gas at the same temperature and pressure. You can vary the pressure with the slider. Select "compare departure functions" to view departure functions for all three gases as a function of temperature at 15 MPa. Click "show labels" to label each departure function curve with the corresponding gas.
