This simulation shows radioactive decay for the two most abundant uranium isotopes, 235U and 238U. Use the sliders to set the initial number of atoms N0 for all three curves and the generic decay constant λ. Decay curves for 235U (blue) and 238U (orange) are plotted, together with a generic decay curve (green) for the selected decay constant. The red dots mark the half-life of each decay.

Radioactive decay has the form of exponential decay:

$$N(t) = N_0\, e^{-\lambda t}$$

where \(N(t)\) is the number of nuclei remaining at time \(t\) (in years) for an initial number \(N_0\) in the sample, and \(\lambda\) is the decay constant. Each isotope's \(\lambda\) is calculated from its half-life \(t_{1/2}\), the time for half of the sample to decay:

$$\lambda = \frac{\ln 2}{t_{1/2}}$$

At the half-life, half of the initial sample remains:

$$N(t_{1/2}) = \frac{N_0}{2} = N_0\, e^{-\lambda t_{1/2}}$$

where \(N_0\) is the initial number of nuclei and \(N(t_{1/2})\) is the number of nuclei remaining.

The green curve is a generic decay for the decay constant \(\lambda\) set with the slider.
